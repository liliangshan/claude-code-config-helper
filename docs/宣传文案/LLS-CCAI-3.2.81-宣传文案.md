# 少折腾安装，左右并行，边写代码边出图

写代码时，真正打断节奏的，往往不是问题有多难，而是工具有多绕。

装 CLI 要查命令，换任务要切会话，需要图标、插画或封面时，还得打开另一个网站、自己琢磨提示词。

**LLS CCAI（Claude Code Config Helper）这次把三件事放到了一起：CLI 快速安装更新、左右并行任务、内置图片 MCP。**

让准备工作更简单，让开发过程更连贯。

## 01｜安装更新 CLI，不必从一堆终端命令开始

想用 Claude Code，不想先研究怎么安装？

打开扩展，跟着引导选择下载来源，就能在 VS Code 里完成 CLI 下载、校验和配置。已经安装过，也可以直接选择现有 CLI，不用再装一遍。

- **新用户快速上手**：语言、CLI、模型配置顺着做，不必到处找入口。
- **老用户轻松更新**：在设置里检查更新，确认后下载安装，进度直接可见。
- **下载来源可选**：支持官方 npm，也可以按需选择 npmmirror 镜像。
- **已有环境继续用**：保留旧版本文件，不强行覆盖外部安装的 CLI。

**少查几篇教程，少来回切几个终端，把时间留给真正要做的事。**

## 02｜左右各开一个任务，不必让一段对话承担所有事情

一边写功能，一边查问题；一边搭页面，一边整理接口。

点击「并行会话」，直接打开另一侧聊天。主任务继续推进，辅助任务独立展开，编辑区留给代码。

比如：

- **右侧写新功能，左侧分析报错**，不用把排查过程塞进主任务的长对话。
- **右侧开发页面，左侧整理接口说明**，两个方向同时推进。
- **右侧实现方案，左侧检查测试思路**，需要时再把结论带回来。

两个会话各自保留上下文、模型选择和权限设置。你可以给不同任务选择不同模型，不必为了临时查一个问题，把主对话越聊越乱。

**不是把聊天窗口堆满屏幕，而是让两个任务各有位置。**

## 03｜内置图片 MCP：你提需求，模型写提示词、调用生成

做项目需要的不只是代码，也可能是一枚应用图标、一张插画、一张文章封面，或者页面里的图片素材。

**不必先把自己变成“提示词工程师”，也不用把图片需求拆出去单独处理。**

现在，LLS CCAI 已内置图片 MCP。点击任务流后面的「图片」入口，可以选择已有提供商的模型，也可以独立配置 Base URL、API Key 和图片模型。

**不需要再额外安装一套图片 MCP 包。**

配置好之后，直接说你需要什么：

> 给这个记账应用设计一枚简洁、容易辨认的图标，风格和当前界面一致。

> 为这篇技术文章生成一张封面，突出主题，画面不要太杂。

> 给首页做一张温暖的橘猫插画，色调配合当前页面。

你负责说明用途、风格和想表达的内容，**聊天模型负责结合需求和项目上下文编写生图提示词，再调用所选图片模型生成素材。** 尺寸等调用参数也由模型按需求提交，不必先到配置页改一遍。

图片在后台生成，你可以继续推进其他工作，不必守着任务反复查询。完成后，结果自动回到发起任务的会话，模型再根据原需求继续处理。

- **不只做配图**：图标、插画、封面、页面素材，都可以从一句需求开始。
- **提示词交给模型**：不用先自己整理成完整的生图指令，直接说清楚目标即可。
- **兼容的图片编辑**：已有图片需要调整，也可调用服务商支持的 JSON 图片编辑能力。
- **全局配置一次**：左右聊天区和编辑区会话共用图片连接，不用重复填写。
- **生成完成自动通知**：不用让模型反复轮询，也不用来回切页面查看。
- **图片直接保存到工作区**：任务记录和图片统一放在 `.LLSOAI/openapi-image-generation/`，方便后续使用。

**你说“这个项目需要什么”，模型负责把需求变成提示词，再把生成结果带回开发流程。**

## 把三个能力连起来，开发节奏就不一样了

先快速配置好 CLI 和模型。

右侧推进主任务，左侧处理辅助工作。

需要图标、封面或其他图片素材时，直接向模型提需求，让它写提示词、调用图片工具在后台生成；完成结果自动送回原会话，再接着推进项目。

**安装少折腾，任务不挤在一起，代码和图片都围绕当前工作区展开。**

这就是 LLS CCAI 这次更新想带来的体验：不是再加一个需要频繁切换的工具，而是少几次切换，多一点连贯。

### 了解更多

- **GitHub 项目**：<https://github.com/liliangshan/claude-code-config-helper>
- **VS Code 扩展名称**：Claude Code Config Helper

> 使用说明：模型服务和 API Key 需自行配置，扩展不包含免费额度。图片请求和后续模型处理可能计费，具体能力以服务商为准。并行会话各有上下文，但不会自动隔离工作区文件，仍需避免同时修改同一文件。CLI 更新可能中断活动任务；文件链接预览取决于使用环境。
